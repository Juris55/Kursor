## ✨ Iespējas / Features / Возможности

### LV — Ko Kursor prot?

| Funkcija | Apraksts |
|----------|----------|
| 🖊️ **Monaco redaktors** | Tas pats redaktors, kas VS Code — sintakses izcelšana, minimap, word wrap, vairākas cilnes |
| 🤖 **MI čats** | Režīmi: Chat, Think, Code, Plan. Dziļuma izvēle. Streaming atbildes |
| 🔌 **50+ MI provideru** | OpenAI, Anthropic, DeepSeek, Groq, lokālie (Ollama, LM Studio), Google AI Studio u.c. |
| 💻 **Terminālis** | PowerShell, CMD, Bash, Zsh. Auto `cd` uz atvērto mapi |
| 🎨 **HTML dizaina ģenerators** | 5 stili, 9 krāsu shēmas, sekciju izvēle. Ģenerē ar MI |
| 🌐 **Pārlūka kontrole** | MI testē tīmekļa lapas — klikšķi, ritināšana, rakstīšana, navigācija |
| 🔒 **Proxy/VPN** | HTTP/HTTPS/SOCKS. Bezmaksas VPN preseti no 4 reģioniem |
| 🧩 **MCP serveri** | Pievieno rīkus: Filesystem, Python REPL, Node.js REPL, Git, Web Fetch |
| 🎨 **Dark/Light tēma** | Pārslēdzams jebkurā brīdī |
| 🌍 **3 valodas** | Latviešu, English, Русский |
| ⚙️ **Pielāgojams** | Fonta izmērs, word wrap, minimap, izkārtojums, automātiskā saglabāšana |
| 🛡️ **Atļauju sistēma** | MI prasa atļauju pirms failu rakstīšanas, URL atvēršanas, komandu izpildes |

| 🌍 **3 languages** | Latviešu, English, Русский |

## 🔧 Build from source / No avota koda / Из исходного кода

```bash
git clone https://github.com/Juris55/Kursor.git
cd Kursor
npm install

# Dev mode with hot reload
npm run electron:dev

# Build for distribution
npm run electron:build:win        # Windows x64
npm run electron:build:win:arm    # Windows ARM64
npm run electron:build:win:x86    # Windows x86
npm run electron:build:win:all    # Windows all architectures
```
